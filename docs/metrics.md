# 统计口径

只统计经过本代理的请求。数据写入 `DATA_DIR/metadata.json`，不读取其他应用的会话日志。

## 用量与缓存

- Token 来自上游 `usage`，不按字符或流式片段数量估算。缺失字段显示 `—`，明确上报的零保留为 `0`。
- 兼容 OpenAI 的 `prompt_tokens_details`、DeepSeek 的缓存命中字段，以及 Anthropic 分项缓存输入。原生分项输入会合并为完整输入；已包含缓存的输入不会重复相加。
- 缓存读取、缓存写入属于输入；推理 Token 属于输出，不重复计入总量。
- 日志中的新增输入 = 完整输入 − 缓存读取，包含新写入缓存的输入。
- 缓存命中率 = 缓存读取 Token ÷ 同批已上报缓存明细请求的完整输入 Token，按 Token 加权。未上报缓存字段的请求不进入分母。

## 速度与延迟

- 实测生成速度 = 输出 Token ÷ 首个至最后一个内容片段的时间，计入推理和工具调用片段。仅有一个内容片段时不计算。
- 区间均速按生成时长加权，排除失败请求。
- 首字延迟从代理收到请求计至首个内容片段，包含上游重试耗时。
- 非流式请求仅计算端到端吞吐：输出 Token ÷ 总耗时。
- 实时速度每秒更新，只使用上游已上报输出量及对应的内容时间。后续片段未附带新用量时，不因此降低已测速度。并发时合计已上报请求的速度，并标明覆盖数。
- 上游仅在末尾上报用量时，进行中显示等待上报，旁边保留最近一次成功实测值。

## 参考成本

优先级：上游 `usage.cost`（USD）→ 手动单价 → models.dev 报价。参考成本不代表订阅实际扣费。

单价单位为 USD / 百万 Token。估算请求标记 `≈`，并保存当时采用的单价、来源、供应商和报价时间。更新单价不改写历史。

models.dev 优先匹配实际渠道和精确模型 ID；只有来源明确时才采用官方或唯一候选的参考价。多义匹配需要手动选择，不默认取最低价。缓存价格、上下文档位或推理差异价格所需的用量字段不完整时，不猜算成本。

手动定价未填缓存单价时沿用输入单价。目录价格缺少适用的缓存单价时，不估算已知缓存消耗。

价格缓存保存在 `models-dev-pricing.json`，有效期 24 小时。启动时和过期后按需刷新，也可在页面手动同步。拉取失败会保留旧缓存，且不覆盖手动单价。

## 时间、留存与升级

- 聚合与热力图使用 UTC；请求详情显示浏览器本地时间。
- 按日聚合保留约 366 天，按小时保留约 32 天；详细请求保留最近 2,000 条。
- 模型和上游筛选同时作用于总览、趋势、分组与日志；热力图使用自身标注的时间范围。请求页指定 UTC 日期后，该日期优先于总览时间范围。
- 升级时从仍保留的详细请求回填聚合和维度。旧版本已丢弃的请求、未记录的用量无法补回，旧分组覆盖不足时页面会提示。
- 较早日期可能仍有聚合数据，但已没有逐条请求可查。CSV 只包含保留且符合当前筛选条件的详细记录。

## 上游路由

| 管道 | 偏好参数 |
| --- | --- |
| OpenRouter 直连 | 顶层 `provider.only / order` |
| Vercel 规划器 | `providerOptions.gateway.only / order / sort` |

模型归属与渠道清单可能变化，以控制台探测结果为准。多个候选按优先级逐个尝试；流式内容开始返回后无法切换渠道，后续断流会记录为失败。
