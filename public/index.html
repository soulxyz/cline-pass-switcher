这些指标如何计算？

Token 来自上游 usage；缓存读取与写入属于输入，推理属于输出，不重复相加。输入命中占比 = 缓存读取 Token ÷ 同批已上报缓存明细请求的完整输入 Token，按 Token 加权；未上报缓存信息的请求不纳入分母。未命中输入包含新写入缓存的输入。上游未上报时显示「—」，明确上报 0 时显示 0。生成速度 = 输出 Token ÷ 首个至最后一个内容片段的时间（含推理、工具调用片段）；单片段响应无法测算。总览按生成时长加权，排除失败请求。首字延迟从代理接收请求计至首个内容片段，包含上游重试。非流式仅提供端到端吞吐（输出 Token ÷ 总耗时）。进行中若尚未收到 usage，显示「等待用量」，完成后补全。
